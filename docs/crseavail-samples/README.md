# crseavail response samples

Real responses from `https://www.sis.hawaii.edu:9350/crseavail/api/*`, captured 2026-11-25 (user-authorized),
trimmed to a few rows. Per-subject files are `termCode=202710&campusCode=MAN&subjectCode=ICS`, filtered to
CRNs 77062 (ICS 311-001) and 71367. `crosslist.json` is `termCode=202710`, one full group plus a few rows.
`subjects.json` is the first rows of the no-parameter call. All requests sent `X-Recaptcha-Token: undefined`.
Numbers are JSON numbers; codes and dates are strings. Used by the design in
`docs/superpowers/specs/2026-11-25-crseavail-hybrid-ingest-design.md`.
Instructor names, emails and Banner user ids are replaced with placeholders.
